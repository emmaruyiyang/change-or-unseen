# change-or-unseen

Streaming video memory: when a state is not visible, did it change or was it just unseen? CS2883R research project.
Benchmarks: STORM-Bench, OVO-Bench, MemInStream (SoccerNet probe removed 2026-11-24; code in `_backup/`).

## Layout

Two folders hold the code: `methods/` (the memory methods) and `probes/` (the perception probes and baselines that
measure what memory can gain). Data and caches stay in `data/`.

| Path | What it holds |
| --- | --- |
| **`methods/`** | |
| `methods/belief/` | Belief memory (method in `proposal/method_v2.md`): `evidence.py` caches frozen-VLM clip evidence (MLX or `--backend hf` for CUDA), `memory.py` is the belief update and decision read-out, `fit_eval.py` fits it and compares baselines. `colab_run.ipynb` runs it on Colab; results in `REPORT.md` |
| `methods/stamem/` | StaMem v0: state-aware write/evict policy under a frame budget, baselines (FIFO / uniform / dedup), no-VLM coverage and VLM accuracy on STORM and OVO long videos. Also holds the shared long-video loaders (`longdata.py`, `fetch_long.py`). See `methods/stamem/README.md` |
| **`probes/`** | P0 options only · P1 all frames up to the query · P2 evidence frames only · P3 evidence frames → text note → answer |
| `probes/storm/` | STORM go/no-go pilot (was `gonogo/`): `probe.py` (P0–P3; also the shared data loading, frame sampling, prompts and MLX wrapper that every other script imports), `status_probe.py`, analysis scripts, `PREREGISTRATION.md`, `REPORT.md`, `results/` |
| `probes/ovo/` | `ovo_probe.py` (P0/P1 on the 8-video sample), `ovo_long_probe.py` (P0–P3 on long-video backward questions; `--data meminstream` runs MemInStream), `ovo_analyze.py`, `results/` (MemInStream results are here too: `meminstream_qwen3vl8b.jsonl`) |
| `probes/meminstream/` | `fetch.py` (stratified sample, single videos by HTTP range), `p2_probe.py` (self-contained P2: frames, evidence selection, prompt, runner) |
| `viz/` | `流式回放 STORM · OVO · SoccerNet.html`, the replay page (self-contained, opens by double-click), generated by `build_replay.py` |
| `proposal/` | Proposal drafts and `method_v2.md` |
| `data/storm/examples/` | STORM-Bench example episodes (7 videos + per-episode `*.questions.jsonl`) |
| `data/storm/STORM-Bench 流式回放.html` | The original STORM replay page; `build_replay.py` uses it as the template, so keep it |
| `data/storm/frames/` | 1 fps frame cache for STORM (regenerated on demand) |
| `data/ovo/` | OVO-Bench annotations (`ovo_bench_new.json`), the 8-video sample (`videos/`, `samples.jsonl`), long-video question lists (`long_samples.jsonl`, `long_backward.jsonl`), the tar header index used to fetch single videos (`src_videos_index.jsonl`), frame caches |
| `data/meminstream/` | MemInStream annotations (`annotations.json`), the 51-question sample (`sample.jsonl`, `videos/`), zip listing, 1 fps frames |
| `data/videomme/` | Video-MME long: 20 videos, 60 questions (`long_samples.jsonl`), frames; not answered yet |
| `_backup/` | Code snapshot taken before the 2026-11-24 reorganisation (old layout) |

## Commands

Probes:

```bash
.venv/bin/python probes/storm/probe.py --model mlx-community/Qwen3-VL-8B-Instruct-4bit --tag qwen3vl8b
.venv/bin/python probes/storm/analyze.py
.venv/bin/python probes/ovo/ovo_probe.py --model mlx-community/Qwen3-VL-8B-Instruct-4bit --tag ovo_qwen3vl8b
.venv/bin/python probes/ovo/ovo_analyze.py
.venv/bin/python probes/ovo/ovo_long_probe.py                       # OVO long-video backward questions, P0-P3
.venv/bin/python probes/ovo/ovo_long_probe.py --data meminstream    # MemInStream sample, P0-P3
.venv/bin/python probes/meminstream/p2_probe.py --dry-run           # MemInStream P2 only, self-contained
```

Methods:

```bash
.venv/bin/python methods/belief/evidence.py --model mlx-community/Qwen3-VL-8B-Instruct-4bit --tag qwen3vl8b --hires
.venv/bin/python methods/belief/fit_eval.py --tag qwen3vl8b
.venv/bin/python methods/stamem/coverage.py --K 4
.venv/bin/python methods/stamem/answer.py --K 4 --summarize
```

Replay page:

```bash
.venv/bin/python viz/build_replay.py
```

Protocol for Baseline A everywhere: frames at 1 fps with timestamp ≤ query time, at most 32 (uniformly thinned, newest kept), longest side 448 px, temperature 0, MLX on Apple M4.
